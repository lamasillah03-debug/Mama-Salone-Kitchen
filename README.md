MAMA SALONE KITCHEN

Website Project Documentation (README)

Project Overview

Mama Salone Kitchen is a restaurant website designed to showcase Sierra Leonean traditional dishes and provide customers with information about the restaurant. The website gives visitors an opportunity to explore different food options, learn about the restaurant, view food pictures, and find contact information.

The main purpose of this project is to promote Sierra Leonean food and culture through an attractive, simple, and user-friendly website.

Project Objectives

The objectives of the Mama Salone Kitchen website are to:

1. Promote traditional Sierra Leonean meals and local food culture.
2. Provide customers with information about the restaurant.
3. Display different food items through an organized menu.
4. Allow visitors to view food pictures in the gallery.
5. Make it easy for customers to contact the restaurant.
6. Create a simple and attractive browsing experience.

Website Features

The website consists of five main pages:

Home Page: Introduces Mama Salone Kitchen and welcomes visitors to the website. It provides an overview of the restaurant and highlights its food offerings.

Menu Page: Displays the different meals available at the restaurant, allowing customers to explore the food options.

About Us Page: Provides information about Mama Salone Kitchen, its background, purpose, and commitment to serving delicious traditional meals.

Gallery Page: Displays pictures of different dishes and food presentations to give visitors a visual experience of the restaurant’s offerings.

Contact Us Page: Provides contact information so customers can reach the restaurant for enquiries and other information.

Technologies Used

The website was developed using the following technologies:

* HTML5: Used to structure the website and organize its content.
* CSS3: Used to style the pages, add colours, arrange layouts, and improve the overall appearance.
* Visual Studio Code: Used as the code editor for developing and managing the website.

Website Structure

The project is organized into different files and sections to make the website easy to manage and maintain.

1. index.html – Homepage
2. menu.html – Menu page
3. about.html – About Us page
4. gallery.html – Gallery page
5. contact.html – Contact Us page
6. style.css – Main stylesheet responsible for the website’s design and layout.
7.  images/ – Folder containing the pictures used throughout the website.

Design and User Experience

Mama Salone Kitchen uses a simple, attractive, and organized design. The layout is created to make navigation easy for visitors. The colours, images, headings, and content are arranged to reflect the restaurant’s identity and create a welcoming atmosphere.

The website focuses on readability, accessibility, and easy navigation so that visitors can find the information they need without difficulty.

Project Purpose and Importance

This project demonstrates how web development technologies can be used to create an online platform for a restaurant. It helps promote local businesses, introduces customers to Sierra Leonean dishes, and provides an online presence for Mama Salone Kitchen.

It also provides practical experience in HTML and CSS, website structure, page linking, styling, and basic web design principles.

Conclusion

The Mama Salone Kitchen website is designed to provide an attractive online platform for showcasing traditional Sierra Leonean food and restaurant information. Through its homepage, menu, about us, gallery, and contact pages, the website gives visitors a convenient way to explore the restaurant.

Developing this project has improved practical knowledge of website design and development, particularly in using HTML and CSS to build and organize a complete multi-page website.
